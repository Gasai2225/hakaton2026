# Личный кабинет Garden

## Локальная проверка

Откройте [регистрацию](http://127.0.0.1:5173/register) и создайте аккаунт с именем, почтой и паролем от 8 до 128 символов. В разделе «Проекты» можно завести несколько черновиков. На странице «Шаблоны» доступны три шаблона Garden и публикации сообщества. Применение шаблона создаёт отдельный проект.

Чтобы проверить совместную работу на одном компьютере, зарегистрируйте второй аккаунт в приватном окне. Владелец открывает управление доступом к проекту, вводит адрес второго аккаунта и копирует ссылку. Получатель открывает её в приватном окне, входит с приглашённым адресом и принимает приглашение. После этого оба могут открыть один граф. Владелец может отозвать доступ там же. Для этой проверки достаточно регистрации по паролю и ссылки, которую владелец передаёт вручную.

## Общий адрес

На другом компьютере адрес `127.0.0.1` ведёт к этому компьютеру. Для работы команды разместите редактор и `/api/` на общем HTTPS-домене. Прокси должен передавать запросы API на Garden, клиентские маршруты должны открывать редактор. Установите на сервере `GARDEN_PUBLIC_ORIGIN`, например `https://garden.example.org`. Укажите только схему, домен и при необходимости порт.

## Быстрый вход

Зарегистрируйте веб-приложение у нужного провайдера. Адреса возврата должны в точности совпадать с общим адресом редактора. В таблице используется домен `garden.example.org`.

| Способ входа | Переменные сервера | Разрешённый адрес возврата |
| --- | --- | --- |
| Google | `GARDEN_GOOGLE_CLIENT_ID`, `GARDEN_GOOGLE_CLIENT_SECRET` | `https://garden.example.org/api/auth/oauth/google/callback` |
| VK ID | `GARDEN_VK_CLIENT_ID` | `https://garden.example.org/api/auth/oauth/vk/callback` |
| Mail.ru через VK ID | Тот же `GARDEN_VK_CLIENT_ID` | `https://garden.example.org/api/auth/oauth/mailru/callback` |

Для Google создайте клиент типа «Web application», добавьте адрес возврата и настройте аудиторию приложения. Garden использует профиль и подтверждённый адрес почты. [Настройка веб-приложения Google](https://developers.google.com/identity/protocols/oauth2/web-server)

В кабинете VK ID зарегистрируйте веб-приложение, подключите получение email и добавьте оба адреса возврата. VK ID поддерживает вход через Mail.ru. Garden выбирает этот способ параметром `provider=mail_ru`. [Официальный VK ID SDK](https://github.com/VKCOM/vkid-web-sdk)

После изменения переменных перезапустите API. Редактор включает способы входа, для которых заданы параметры. При первом входе пользователь разрешает передать свой email. Если адрес уже занят аккаунтом, созданным другим способом, Garden предлагает войти первоначальным способом.

## Почтовые приглашения

Ссылка приглашения одноразовая и действует семь дней. Для отправки писем Garden использует следующие переменные сервера.

| Переменная | Значение |
| --- | --- |
| `GARDEN_SMTP_HOST` | Хост SMTP-сервера |
| `GARDEN_SMTP_FROM` | Разрешённый адрес отправителя |
| `GARDEN_SMTP_MODE` | `starttls` по умолчанию или `ssl` |
| `GARDEN_SMTP_PORT` | По умолчанию 587 для STARTTLS и 465 для SSL |
| `GARDEN_SMTP_USER`, `GARDEN_SMTP_PASSWORD` | Данные входа, если сервер требует авторизацию |

Для ссылок в письмах нужен HTTPS-адрес в `GARDEN_PUBLIC_ORIGIN`. Если SMTP не настроен, владелец может скопировать ссылку в окне доступа.

## Модели для проектов

`GARDEN_TEAM_CONNECTIONS` задаёт доступные командным проектам идентификаторы подключений через запятую. По умолчанию доступен `ollama`. Добавьте идентификатор уже настроенного подключения, если участники должны использовать его в своих графах. Ключи провайдеров хранятся на сервере.
